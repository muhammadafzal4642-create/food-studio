# The Food Studio – Indian & Asian Cuisine in Falaj, Oman

A responsive web application for **The Food Studio**, showcasing authentic Hyderabadi and Thalassery Biryanis, sizzling Asian noodles and fried rice, tandoori specialties, special lunch combos, and direct WhatsApp ordering.

## Features

- **Interactive Menu**: Explore Biryani specialties, Asian noodles & fried rice, Indian gravies, and special lunch combos.
- **WhatsApp Direct Ordering**: Order food items seamlessly with pre-filled WhatsApp messages.
- **Table Reservation & Contact**: Direct contact, location directions, and opening hours for Falaj, Oman.
- **Modern Responsive Design**: Built with React 19, Tailwind CSS v4, Lucide icons, and Motion animations.

## Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Animations:** Motion
- **Deployment:** Vercel

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
```

The output will be created in the `dist` directory.

### Deploy to Vercel

1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and log in.
3. Click **Add New Project** and select this repository (`food-studio`).
4. Framework preset will automatically detect **Vite**.
5. Click **Deploy**.
